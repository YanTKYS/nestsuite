# NestSuite リリース前確認チェックリスト

毎リリースで通す**恒久的な**確認項目のみを置く。
機能ごとの初回検証手順は、その version の PR で確認したうえでここへ蓄積しない。
実装ルールは [`docs/development/nestsuite-development-guidelines.md`](../development/nestsuite-development-guidelines.md) を参照。

---

## 1. version・文書

- [ ] `NestSuite.csproj` の `AssemblyVersion` / `FileVersion` / `InformationalVersion` が対象バージョンへ更新されている
- [ ] `ApplicationVersionTests.cs` の期待値が対象バージョンと一致している
- [ ] NoteNest schema が `1.4.2` のまま維持されている（変更した場合は `docs/architecture/schema-versioning-policy.md` のチェックリストに従う）
- [ ] `docs/release-notes.md` に対象バージョンのエントリがある
- [ ] そのエントリに保存形式・session 形式・schema 変更の有無が明記されている
- [ ] 完了した backlog 項目が `docs/backlog.md` から削除されている
- [ ] README・利用ガイドの記述が今回の変更と矛盾していない
- [ ] About のバージョン表記が最新になっている

---

## 2. ビルド・テスト

- [ ] `dotnet build NestSuite.sln -c Release` が通る
- [ ] `dotnet test` が全件通る
- [ ] GitHub Actions CI green
- [ ] UI Smoke Test green

---

## 3. 起動

- [ ] `NestSuite.exe` → Temp タブがアクティブな状態で起動する（前回セッションがあれば復元後にそのタブがアクティブ）
- [ ] `NestSuite.exe <file>` → `.nestsuite` / `.notenest` / `.chatnest` / `.ideanest` / `.txt` が対応 Workspace タブで開く
- [ ] `NestSuite.exe --nestsuite` → 引数なしと同じ動作になる（互換フラグ）
- [ ] 未対応拡張子・読込失敗時はエラーを表示し、アプリ自体は起動したままになる
- [ ] 復元できないファイルがある場合、復元失敗通知が表示され、FileNotFound は再試行解除を選べる

---

## 4. タブ操作

- [ ] ファイル > 新規作成、およびタブバー「＋」から NoteNest / IdeaNest / ChatNest / テキスト を新規作成できる
- [ ] ツールメニューの項目が「横断検索」「デバイス移行パックをエクスポート」「デバイス移行パックをインポート」だけである
- [ ] `Ctrl+Tab` / `Ctrl+Shift+Tab` / `Ctrl+1`〜`Ctrl+9` でタブを切り替えられる
- [ ] タブのドラッグで並び替えでき、挿入位置インジケーターが表示される
- [ ] Temp タブは左端固定で、ドラッグ・中クリック・「他のタブを閉じる」で閉じない
- [ ] タブ見出しが「絵文字 + 拡張子なしファイル名」形式（Temp タブは「Temp」のみ）で表示される
- [ ] 未保存タブに `●` が表示され、保存後に消える
- [ ] タブのツールチップが「種類 / ファイル名 / 場所 / 状態」（Temp タブは「種類 / 説明 / 保存」）で表示される
- [ ] タブをピン留めすると Temp タブ直後へ移動し、見出しに 📌 が付く
- [ ] タブが多いときタブストリップ右端の「▾」で一覧を表示できる

---

## 5. タブの独立性

- [ ] 複数タブで内容が混ざらない（同種 Workspace 同士・異種 Workspace 間とも）
- [ ] タブ A の保存・編集がタブ B の内容・未保存状態に影響しない
- [ ] 既に開いているファイルを再度開くと、重複タブを作らず既存タブがアクティブになる

---

## 6. 保存・復元

- [ ] 3 Workspace とも新規保存・上書き保存ができ、`.tmp` が残らない
- [ ] 上書き保存で `.bak` が更新される（`AtomicFileWriter` の `File.Replace` 経由。新規保存時は作らない）
- [ ] 自動保存では `.bak` が更新されない
- [ ] 名前を付けて保存で `.nestsuite` として保存され、元ファイルが残る
- [ ] 別タブで開いているパスを保存先に指定するとエラーになり、保存が中止される
- [ ] 未保存タブを閉じる／アプリを終了すると「保存 / 保存しない / キャンセル」が表示される
- [ ] 未保存タブが 2 件以上あるときは、終了時にまず件数サマリが表示される
- [ ] 無題タブを残したまま異常終了させると、次回起動時に下書き復元を確認される
- [ ] 再起動でセッション（保存先を持つタブ・ピン留め・アクティブタブ）が復元される

---

## 7. シングルインスタンス・ファイル関連付け

- [ ] ヘルプ > ファイル関連付けの設定 から登録・解除でき、状態表示が実際のレジストリと一致する
- [ ] 起動中に関連付けファイルをダブルクリックすると、既存ウィンドウにタブが追加される（最小化中は前面化）
- [ ] 未起動時にダブルクリックすると、前回セッション復元後に対象ファイルが追加タブとして開く
- [ ] 開けない `.nestsuite` をダブルクリックすると理由が通知される（無言で終わらない）
- [ ] ファイル指定なしで 2 プロセス目を起動しても既存ウィンドウが変化しない

---

## 8. NoteNest

- [ ] ノートブック・ノートの追加 / 名前変更 / 複製 / 削除ができる
- [ ] ステータスバーに現在位置（行 / 列 / 文字数 / 行数）が表示され、カーソル移動へ追従する
- [ ] 表示 > テキストを折り返す の ON / OFF が全 NoteNest タブへ反映され、再起動後も保持される
- [ ] 本文の `[TODO]` / `[FIXME]` / `[NOTE]` 行がエディタ上でハイライトされ、右ペインのマーカー一覧に出る
- [ ] `[[` 入力でノートリンク補完 Popup が表示され、Tab で挿入・Esc でキャンセルできる
- [ ] リンク切れ確認ダイアログが該当箇所を一覧表示する
- [ ] 参照のあるノートをリネームするとリンク影響の警告が表示される
- [ ] 右ペインの絞り込みがマーカー一覧と互換タスク一覧の両方に効き、Esc / ×で解除できる
- [ ] 右ペインの「全件コピー」で、表示中の項目だけが Markdown でコピーされる
- [ ] マーカー一覧・リンク一覧を Tab で到達し、上下キー選択・Enter でジャンプできる
- [ ] `Ctrl+F` / `Ctrl+H` の全ノート検索・置換が動作する

---

## 9. IdeaNest

- [ ] カードをクリックすると詳細画面が開き、タイトル・本文・タグ・色・ピン留め・アーカイブを編集できる
- [ ] 詳細画面を閉じる / 前へ・次へで移動する / `Ctrl+S` で編集内容が保存される
- [ ] 何も変更せず閉じた場合、`UpdatedAt` が更新されない
- [ ] 新規作成画面で何も入力せず閉じるとカードが追加されない（`Ctrl+S` 後に閉じても二重作成しない）
- [ ] タグフィルタ・検索で絞り込め、一致箇所がカード内でハイライトされる
- [ ] 削除・アーカイブを Undo できる
- [ ] カード 0 件・検索結果 0 件それぞれの空状態テキストが表示される

---

## 10. ChatNest

- [ ] `Ctrl+Enter` で投稿、`Ctrl+← / →` で発言者切り替えができる
- [ ] 入力欄フォーカス中に `Shift+← / →` が発言者切り替えとして処理されない（Shell のタブ切り替えになる）
- [ ] 発言の編集・削除・単体コピー・並び替えができる
- [ ] 過去メッセージを Tab で到達し、Shift+F10 / コンテキストメニューキーで操作メニューを開ける
- [ ] `Ctrl+F` の会話内検索が動作する
- [ ] 日付をまたぐ会話に日付区切りヘッダーが表示される

---

## 11. TempNest

- [ ] Temp タブに 2×2 の 4 スロットが表示され、タイトル・本文を入力できる
- [ ] スロットのコピー・クリアが動作し、空スロットではボタンが無効になる
- [ ] 入力が自動保存され、再起動後も残る（`%APPDATA%\NoteNest\tempnest.json`）
- [ ] Temp タブ選択中の `Ctrl+S` が無視される（保存ダイアログが開かない）
- [ ] TempNest が最近使ったファイル・セッション復元・未保存確認の対象にならない
- [ ] スロット本文を NoteNest ノート / IdeaNest カードへ転送できる（0 件 / 1 件 / 複数件それぞれの転送先解決）

---

## 12. テキスト（`.txt`）

- [ ] `.txt` を開いて編集・上書き保存でき、`.nestsuite` へ変換されない
- [ ] 新規テキストが UTF-8（BOM なし）で保存される
- [ ] 既存ファイルの文字コード・BOM・改行コードが保存後も維持される
- [ ] 非対応文字コード（Shift_JIS 等）は開けず、元ファイルが変更されない
- [ ] `.txt` の Windows 既定アプリ設定が変更されない

---

## 13. Shell 横断検索

- [ ] `Ctrl+Shift+F` で開き、既定では開いているタブのみが対象になる
- [ ] 「最近のファイルも検索」ON で未オープンの最近ファイル上位 5 件が加わる
- [ ] 結果クリックで対象ファイルを開ける
- [ ] `Escape` / ×で閉じ、開く前の場所へフォーカスが戻る

---

## 14. 別ウィンドウ表示

- [ ] NoteNest / IdeaNest / ChatNest のタブを「別ウィンドウで表示(_D)」で分離できる（TempNest には項目が出ない）
- [ ] 別ウィンドウの ×・「このタブへ戻す(_B)」で Shell タブへ戻る（保存確認なし）
- [ ] Shell の最小化・復元に別ウィンドウが連動する
- [ ] 分離中のタブを Shell 側で閉じると保存確認が表示される
- [ ] 再起動後は全タブが Shell に統合された状態で開く（分離状態は保存されない）

## 15. 表示・アクセシビリティ

- [ ] Light / Dark を切り替えても、マーカー色・タスク状態・選択ハイライトが判別できる
- [ ] テーマ設定が再起動後も保持される
- [ ] 主要操作（保存・すべて保存・コピー・エクスポート・TempNest クリア）でステータスバーに完了メッセージが出て自動的に消える
- [ ] 無効なメニュー・ボタンに理由を示すツールチップが表示される
- [ ] メニュー・タブコンテキストメニューのアクセスキーが重複していない
- [ ] アイコン・記号のみのボタンに `AutomationProperties.Name` が設定されている
