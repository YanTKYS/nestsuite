# NoteNest タスク管理縮退方針

NoteNest は、プロジェクト単位でノートを整理し、本文中のマーカーとノート間リンクから
作業ポイントを見つける Workspace とする。本格的なタスク管理は主目的にしない。

## 中心機能として維持するもの

- ノートブック / ノート / 本文エディタ
- 本文中のマーカー自動抽出（`TODO` / `FIXME` / `NOTE` 等）とマーカー一覧
- ノート間リンク
- Markdown エクスポート
- 検索

作業ポイントは、タスクを別オブジェクトとして管理するのではなく、
本文へ書いたマーカーを一覧で見つける形へ寄せる。

## タスク機能の現在地

タスク機能は**互換表示**へ縮退済みで、通常利用の主導線には出さない。

- タスク新規作成導線（右ペインの「タスクを追加」・グループの「+」）は UI から外している
- 既存タスクが 0 件なら、タスク欄は「作業ポイントは本文の TODO / FIXME で管理できます。」の
  一言だけを表示し、`HasNoTasks` に応じて下段の高さを詰めてマーカー / リンク領域へ譲る
- 既存タスクが 1 件でもあれば「タスク（互換）」として表示し、完了切替・コメント編集・
  関連ノート付け替え・削除・移動といった既存操作はそのまま使える

## 既存データ互換（最優先）

既存の `.notenest` データは壊さない。UI 上でタスク導線をさらに下げる場合も、これを優先する。

- 既存タスク情報を削除しない / 読めなくしない
- 保存形式を変更しない
- タスク縮退を理由に schema bump しない（NoteNest schema `1.4.2` を維持する）

保存形式変更を伴うタスク情報の削除・移行は、必要性が明確になるまで実施しない。
